## 配色の計算

sRGBの相対輝度をPythonで計算し、(明るい側の輝度 + 0.05) / (暗い側の輝度 + 0.05)で比率を求めた。
表の表示だけを小数点以下二桁に丸め、判定には丸める前の値を使った。
色の値は [デザイントークン案](design-tokens.json) と一致することを確認した。

| 組み合わせ | 比率 | 判定 |
| --- | --- | --- |
| paper / panel | 12.30:1 | 不透明な文字色の組として4.5:1以上 |
| muted_panel / panel | 8.49:1 | 不透明な文字色の組として4.5:1以上 |
| ink / paper | 10.99:1 | 不透明な文字色の組として4.5:1以上 |
| muted_paper / paper | 5.04:1 | 不透明な文字色の組として4.5:1以上 |
| primary_ink / primary | 9.11:1 | 不透明な文字色の組として4.5:1以上 |
| paper / secondary | 7.20:1 | 不透明な文字色の組として4.5:1以上 |
| success / paper | 5.50:1 | 不透明な文字色の組として4.5:1以上 |
| warning / paper | 5.13:1 | 不透明な文字色の組として4.5:1以上 |
| danger / paper | 5.53:1 | 不透明な文字色の組として4.5:1以上 |
| boundary / panel | 4.62:1 | 不透明な文字色の組として4.5:1以上 |

上記は提案色の不透明な組み合わせの確認で、現行ゲームの測定結果ではない。
背景の海と合成される透明面、写真、実際のフォーカス、拡大表示は改修後に確認する。
これだけでゲーム全体のWCAG適合を宣言しない。
基準の参照元は [S24](sources.md#s24)、操作対象の寸法は [S25](sources.md#s25) を参照する。
