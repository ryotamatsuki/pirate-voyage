## 分析から除外したもの

取得しただけで内容を確認していない画像は、この台帳に含めない。
ABZÛの先頭の告知画像は賞のバッジが中心だったため、景観の根拠から除外した。
Outer Wildsの2016年の大きなコンセプト画像は取得に失敗し、本文の記述だけを使った。
参照先の画像が変わった場合は、以前の観察と現在の画像を混ぜず、再確認の日付とハッシュを残す。
