# デザイン調査の参照元

確認日：すべて2026年10月1日（日本時間）。
対象：公開されている受賞記録、開発者資料、公式画像、批評。
公開日が本文から確定しないページは、推測の年月日を付けない。

各IDは [調査報告](research_2026-10-01.md) と [改修の引き継ぎ](handoff.md) で共通に使う。
本文は要約と本作への分析であり、参照元の記事の転載ではない。
第三者の画像は [画像台帳](reference-media.md) のリンクから確認する。

## S01

- 参照元：[BAFTA Games Artistic Achievement](https://www.bafta.org/awards/games/artistic-achievement/)
- 発信者：BAFTA。一次資料。年度別の受賞と候補を掲載。
- 確認した事実：2019年Return of the Obra Dinnと2013年Journeyは受賞、2017年ABZÛと2018年ブレス オブ ザ ワイルドは候補。
- 用途：美術に関する外部評価の根拠。
- 限界：候補は受賞と区別する。個々の画面やスマートフォンUIが使いやすいことを保証しない。

## 再調査時の手順

受賞の根拠を使う場合は、主催者の年度と部門名を再確認する。
画像を見る場合は、出典ページと画像台帳のIDを対応させ、宣伝素材、実際のUI、開発中の画面を区別する。
画像URLが失効した場合は、公式ページの更新後の画像を使い、台帳に変更を追記する。
以前の画像と違う場合はハッシュを更新し、同じ観察の証拠として自動的に置き換えない。
