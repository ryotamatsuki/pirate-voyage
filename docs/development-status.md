## 二港試作で実装した範囲

- 自由航海版は直下の `index.html`、ゲーム版は `adventure/index.html`。各版は独立した一ファイルで動く。
- 灯待ち港と松帆港、240ゲーム海里の航海。自動・手動操舵、帆の調整、1・2・4倍速。
- 在庫で動く木材価格、数量ごとの見積り、購入後の資金・船倉表示、取得原価と交易利益。
- 食料、船体HP、補給、修理、一日休む操作、配送の契約積荷と一度だけの40G報酬。
- 120Gで段階2へ改造。船倉20→28、食料上限30→45、HP上限100→115、標準船速6→6.3。船の姿も変わる。
- 海上の救助、契約失敗、再受注、資金0のときの港の手伝いによる復帰。
- 0.05秒の固定刻みと線分による陸地衝突確認。入港の確定後、港とメニュー、背景タブでは時間を進めない。
- 航海日誌40件まで、ブラウザ保存、前回の正常保存、JSONの書き出しと読み込み。WebGL描画に失敗しても保存を書き出せる。

試作では両港を最初から海図に表示する。風による船速補正、予報、未探索領域、遭遇、海戦、専門船員、勢力、灯台の主筋は入っていない。標準所要時間と補給の見積りは穏やかな条件の目安で、入港前の減速と停船中の食料消費により実際の所要量は増える。

## 保存と変更範囲

保存キーは `pirate-voyage:adventure:save:v1`、前回の記録は `pirate-voyage:adventure:backup:v1`。JSONの `schemaVersion` は1、`worldVersion` は `two-ports-1`。v0.1.1は任意の `tutorial` に案内の進行を記録する。項目のないv0.1.0の記録も航海内容を保持して読み込める。仕様書の完成版保存例は設計例であり、試作へ直接読み込むためのJSONではない。将来の五港版には明示的な版移行を実装する。

新規開始、JSONの読み込み、前回の記録への復帰では、現在のゲーム版を置き換えることを確認する。壊れたJSONや範囲外の資源、知らないIDは拒否する。他の版や作品のキーは削除しない。実行コードやHTMLをJSONから評価しない。

自由航海版の基準は `index.html` のGit blob `6f891695f765f358ac79e062561c08006c4703da`。ゲーム版のためにこのファイルを変更していない。ChatGPT Sitesの自由航海版も変更せず、ゲーム版のSites公開は別工程とする。

## 試作での最初の遊び方

灯待ち港で木材配送を引き受け、木材12単位を60Gで買う。松帆港へ出港し、沖で入港を確定する。木材12単位を105Gで売り、配送の40Gを受け取ると185Gになる。120Gで船を補強すると65Gが残る。食料を補給して帰路を選べる。依頼を使わず交易だけで船を育てる遊び方もできる。
