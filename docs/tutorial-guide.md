# 二港試作の初回ガイド

対象：ゲーム版 v0.1.3。M0〜M3の21段階ガイドを維持し、M4a-1の視認・寄り道とM4a-2の観測・航海帳・港への報告を案内する。航路登録、移動短縮と第一章は後続工程。

## 目的と案内役

最初の達成目標は「交易と配送で資金を増やし、120Gで凪灯号を補強沿岸船にする」。補強後も二港の交易と自由航海を続けられ、終了画面は設けない。将来の探索・海賊・灯台の物語を、現在遊べる目標として案内しない。

案内役は仕様書の航海士セナ。初回は技術用語の説明を並べず、その操作をする理由、現在見る数字、次に押す場所を会話と実画面で示す。船員能力や雇用はこの更新で導入しない。

## 進行と実操作

| 手順 | セナが伝えること | 進む条件 |
| --- | --- | --- |
| 目的・資源 | 仕入れ→航海→売却→船の成長。資金・食料・船体・船倉 | 説明を読んで次へ |
| 配送・購入 | 無料で預かる依頼品4単位と、自分で買う木材の区別。購入数量・合計・残る資金 | 受注、実際の購入 |
| 補給・出港 | 食料と修理、往復と予備の目安、行き先 | 補給タブの確認、出港の実行 |
| 停止・操船・倍率 | 停止と再開、自動と手動、帆、海図、カメラ、時間倍率 | 停止と再開を実行し、説明後に倍率を選ぶ |
| 航海中の発見 | 海鳥と浮標、直行・接近・目印、食料の比較、あとで戻る方法 | 任意の選択。直行しても配送・交易のガイドを続ける |
| 浮標の観測・報告 | 旗と泡の筋を読む。分かったこと・未確認・次の行動を航海帳で確認し、松帆港の海図係へ持ち帰る | 観測を確定し、港で報告。任意の寄り道なので21段階の交易ガイドを強制的に進めない |
| 到着・入港 | 自動航海は沖で止まり、自分で入港を確定する | 到着して入港ボタンを押す |
| 売却・配送完了 | 相場と売却合計、通常の売却と依頼品を渡す操作の区別 | 通常木材を売り、配送報酬を受け取る |
| 改造・積み足し | 性能の比較、120Gの費用、改造しても食料は増えない | 補強、食料の補給 |
| 次の航海・保存 | 帰りの行き先、保存と続きから、JSONで端末間移動 | 出港タブの確認、手動保存。JSONは書き出しと後回しを選べる |
| 困ったとき・完了 | 救助の費用、配送の再受注、資金ゼロからの復帰、自由な続行 | 説明の確認。救助を実行させない |

内部では21の小手順を使う。時間経過だけで読書の手順を飛ばさない。取引の失敗は成功として扱わない。配送や改造が済んだ既存記録は、その作業を再実行させない。数量は案内開始時に候補を示すだけで、購入・売却・補給は本人が通常ボタンで確定する。案内による資金・貨物・性能の追加報酬はない。

## 視覚と操作

- 人物のSVG、会話、進行表示、次の操作文を一枚の案内にまとめる。
- 港と日誌ではその画面の中に案内を置く。航海中は海の画面に重ね、舵・帆・倍率・入港を操作できる位置へ配置する。
- 次の場所は金色の枠と矢印で示す。別の施設を開いているときは、先に目的のタブを強調する。
- 「次の操作の場所を見る」で対象へスクロールし、ボタンか入力ならフォーカスを移す。取引を代わりに実行しない。
- 説明欄が長ければ独立してスクロールできる。続きがあることを文字で示し、進むボタンを欄の外に置く。
- 航海して手掛かりを探す手順以外は航海と食料消費を止める。浮標の選択画面も時間を止める。到着時も入港を押すまで止め、説明を読む間に食料を消費させない。
- 浮標の寄り道中は「海図・発見」で記憶した元の行き先へ戻せる。浮標を通過しても再案内を強制せず、日誌と海図に記録を残す。
- 航路や帆を変えた場合は「航路に戻って再開」で松帆港への自動・帆100％へ戻せる。資源や位置を回復・変更しない。
- 閉じる操作で自由に遊べる。遊び方から再案内でき、現在の船・資金・積荷は保つ。

## 観測と報告の案内

接近しただけでは観測済みにしない。到着後は、セナの短い会話と新規SVGで旗と泡の筋に注目させ、「観測して航海帳に記録する」で確定する。分かった潮の境目、所在が未確認の「北の灯」、実行できる松帆港への報告を三つの欄で示す。未実装の場所は訪問できない手掛かりと明示する。

観測画面を閉じると船は停止したまま。海図の浮標か近くの行動ボタンから開き直せる。確定後は「航海帳で記録を確かめる」または元の行き先へ進む操作を選べる。航海帳の記録は直近40件の日誌とは独立して残り、海上・港の双方で読み直せる。

松帆港の「海図係」では、観測・受理の二条件を文字とチェックで表示する。条件が足りない、別の港、すでに受理済みの場合は報告ボタンを使えない。受理すると準備完了を示し、配送・木材売却・補給・通常航海での帰港を案内する。航路登録と移動短縮は次の更新として明示する。

観測画面と海図係の説明中は、交易ガイドを重ねない。市場などへ戻ると既存の案内を続ける。観測・報告は21段階の取引手順を代行せず、資金や船も増やさない。遊び方の第9項で一連の操作を読み直せる。

## 保存と互換性

保存の `schemaVersion: 1` と `worldVersion: two-ports-1` を維持し、任意の `tutorial` を追加する。形式は `{version:1,status:'ACTIVE'|'SKIPPED'|'COMPLETED',step:既知の手順ID}`。古い記録で項目がない場合は導入を提示し、既存の航海データを保持する。

案内の状態はブラウザ保存、前回記録、JSONに含める。未知の版、不正な状態・手順は拒否し、読み込み前の記録を保持する。完了・スキップは再読込み後も維持する。ブラウザ保存が使えない環境では、保存の説明からJSONによる持ち出しへ進める。
